# CRD Berlin

Website of CRD Berlin – https://crd-berlin.de (GitHub Pages).

## Languages

- `index.html` is the English page and the source for all languages.
- German and Spanish texts live in `assets/js/i18n.js` (keys match the `data-i18n="…"` attributes in `index.html`).
- After changing any text, run:

```
python3 tools/build_languages.py
```

This writes `de/index.html` and `es/index.html` and refreshes the structured data (JSON-LD for Google and AI assistants) in all three pages.

## Search engines & AI assistants

- Structured data: LocalBusiness with services, contact point, languages and an FAQPage (generated by the build script).
- `sitemap.xml` with hreflang alternates, `robots.txt` (AI crawlers allowed), `llms.txt` (plain summary for AI assistants).
